# H.E. Hemanth — Developer Portfolio

A responsive React + Vite portfolio for H.E. Hemanth, Java Full Stack Developer.

## Included
- Responsive one-page portfolio with About, Skills, Projects, Experience, and Contact sections
- Live links to SkillX and Career Guidance projects
- Resume PDF at `public/resume.pdf`
- Email, GitHub, and LinkedIn contact links

## Run locally

1. Install Node.js (LTS).
2. Extract this project and open the folder in VS Code.
3. Open a terminal in the project folder and run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

The production-ready site is generated in the `dist` folder.

## Deploy to Vercel
1. Push this folder to a new GitHub repository.
2. In Vercel, import that repository.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

No environment variables are required.

## Personalization
- Replace or add a profile photo if desired.
- Review the resume PDF and contact links before publishing.
- Edit project descriptions or skills in `src/App.jsx`.
